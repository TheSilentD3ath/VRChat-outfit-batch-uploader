## 3) Reddit post

**Where:** r/VRchat (use the **Creations** / appropriate flair) — and check each subreddit's self-promo rules first. r/VRChatAvatars works too. Post the video + a couple of screenshots.

**Title options:**
- `[Free Tool] I got tired of uploading my outfits one by one, so I made a batch uploader (now v3.0)`
- `Made a free Unity tool to upload all your VRChat outfits in one go — v3.0 is out`

**Body:**
```
I run one avatar with a bunch of outfits, each uploaded as its own avatar, and doing
that by hand (detach blueprint, copy the ID, set tags, click the same SDK fixes…
×14) was driving me insane. So I built a tool, and v3.0 just dropped.

What it does:
- ⚡ New outfit? One click "Express" creates + uploads it and fills the Blueprint ID
  back in automatically.
- 🧰 "Upload All" takes a mix of already-uploaded and brand-new outfits and walks you
  through setting up the new ones, then batches everything.
- 👕 Per-outfit accessories (Items) — pick which props upload with which outfit.
- 😀 Per-outfit FaceEmo face-expression menus (capture + tag-swap, no FaceEmo internals
  touched).
- 📊 Live per-outfit budget counters: Contacts (vs the 256 cap + perf rank), realtime
  Lights, and Parameter cost (it knows when VRCFury will compress them).
- 🗜️ One-click texture/VRAM optimization (uses Thry's recommendations, reimplemented so
  you don't need the package).
- 🪟 Cross-platform batching that survives Unity's domain reloads.

It's free and MIT licensed, and it references no third-party types directly — so it
compiles on its own and the VRCFury/FaceEmo/MA features just light up if you have them.

GitHub (code + wiki): https://github.com/TheSilentD3ath/VRChat-outfit-batch-uploader

It's a one-person project, so feedback / bug reports / feature ideas are very welcome.
If it saves you some clicks, that already made my day. 🙏
```
